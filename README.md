# 🐳 Docker Cleanup Automation Tool

A Python-based DevOps automation script that cleans up unused Docker containers, images, volumes, and networks using secure subprocess execution.

This project demonstrates Docker maintenance automation and Python scripting skills used in real-world DevOps environments.

---

## 🚀 Features

- Cleans stopped Docker containers
- Removes unused Docker images
- Deletes unused volumes
- Removes unused networks
- Secure command execution using subprocess
- Error handling and output logging

---

## 🛠️ Tech Stack

- Python 3
- Docker
- subprocess
- os
- Linux OS

---


---

## ⚙️ Prerequisites

- Docker installed and running
- Python 3.x
- Linux OS (recommended)
